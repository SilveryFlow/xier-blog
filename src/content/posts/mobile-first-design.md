# 移动端优先设计的最佳实践

在当今移动互联网时代，移动端优先设计已经不是一种选择，而是必需品。

## 什么是移动端优先？

移动端优先（Mobile First）是一种设计理念，从最小屏幕开始设计，然后逐步扩展到更大的屏幕。

## 核心原则

### 1. 内容优先级

在移动端，屏幕空间有限。我们需要仔细考虑：

- 什么是最重要的内容？
- 用户的核心任务是什么？
- 如何用最少的元素传达最多的信息？

### 2. 触摸友好

- **更大的点击区域** - 至少 44x44 像素
- **足够的间距** - 避免误触
- **拇指区域** - 把重要操作放在拇指易触及的地方

### 3. 性能优化

移动端用户对加载速度更敏感：

- 压缩图片
- 延迟加载
- 减少 HTTP 请求
- 使用 CDN

## UnoCSS 响应式前缀

```javascript
// 移动端样式（默认）
text-sm

// 小屏幕及以上
sm:text-base

// 中等屏幕及以上
md:text-lg

// 大屏幕及以上
lg:text-xl
```

## 总结

移动端优先不仅是技术，更是一种思维方式。从移动端出发，能让我们更好地理解用户需求。
